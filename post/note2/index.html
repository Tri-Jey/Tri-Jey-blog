（Linux）NOTE 2

目录的跳转与查看

  1. pwd（print working directory）:查看当前所在目录的完整路径
  2. ls（list）：罗列出当前目录下的文件和文件夹
  • ls -l（ll）:详细信息（如权限，大小，时间，等）
  • ls a：显示隐藏文件（以点开头的文件）
  • ls -la：（以上两者都进行） 其他内容已在上次写过，不再一一罗列（cd相关）

文件

  1. mkdir（make directory）:新建文件夹
  • 创建单层。如：mkdir text，即创建一个名为text的文件夹；mkdir /note2/text，即在note2（该文件夹已存在的前提下）下创建一个名为text的文件夹
  • 创建嵌套形文件夹。如：mkdir -p a/b/c，即为创建文件a，文件a下一级为文件b，文件b下一级为文件c
  1. touch：
  • 文件不存在时：创建空文件（不是文件夹，只是空文件，需要cat，vim往里面写内容）
  • 文件已存在时：更新文件的访问/修改时间戳（可以用于伪造文件创建时间）
  1. cat（concatenate）：查找文件全部内容
  2. find：查找文件
  • -name 名称：按名称查找，区分大小写
  • -iname 名称：按名称查找，不区分大小写
  • -type f：只查找普通文件
  • -type d：只查找目录
  • -maxdepth n：最多向下查找n层目录
  1. cp（copy）：复制文件/目录
  • cp 源文件 目标 a.文件复制到已存在目录：把文件复制到目标目录里面 b.目录复制到已存在目录：把目标复制到目标目录里面 c.文件复制到已存在文件：用文件内容覆盖目标文件（不可恢复） d.目录复制到已存在文件：报错，无效操作 注意：若目标目录中已存在同名对象，cp可能会覆盖或合并目标的内容
  • cp -r 源目录 目标目录（复制目录时必用）（递归复制），如：cp -r dir_a/dir_x，即把sir_a复制到dir_x中 cp file_a new_file_a,可以把文件复制并改名为new_file_a
  1. mv（move）：移动文件/重命名
  • 移动文件。如：mv note.txt ./mytext/
  • 重命名。如：mv note.txt new.txt
  1. rm（remove）：删除文件/目录，高危
  • rm 文件名：删除文件
  • rm -r文件夹：删除目录
  • rm -rf：强制递归删除（新手不要在根目录用）
  • rm -i：删除前会询问用户。如：输入rm -i text.txt ，会显示rm：是否删除普通文件’text.txt' 输入y回车，删除；输入n回车，不删除。

帮助手册

  1. man：打开命令官方手册。如：man ls，按q退出手册
  2. –help：简易帮助信息，快速看参数。如ls –help

用户 权限

  1. su（switch user）：切换用户
  • su root：切换到root超级管理员（需密码）
  • su 普通用户名 切换普通用户
  1. chomd（change mode）：修改文件/目录读写执行权限

分页查看文件

  1. more（比较老）：分页查看文件
  • +行号：从指定行开始显示
  • +/字符串：第一次匹配的位置开始显示 Space：下一屏；Enter：下一行；q：退出
  1. less（比较现代，比较强）：更强的分页查看文件
  • +行号：从指定行开始显示
  • +/字符串：第一次匹配的位置开始显示
  • -N：显示行号
  • -S：长行不断行，可左右滚动 Space：下一屏；Enter/下箭头：下一行；上箭头：上一行；左箭头：向左滚动长行，通常搭配 -s使用；右箭头：向右滚动长行，通常搭配 -s使用；q：退出；
  1. head：查看文件头部
  • -n 行数：显示头部指定行数，默认10行
  1. tail：查看文件尾部
  • -n行数，显示尾部指定行数，默认10行
  • -f：持续跟踪文件尾部，若有增多则打印（不断有文件写入）

Vim文本编辑器

  1. 先使用vim[待编辑文件路径]打开想编辑的文件，如vim test.txt
  • i：进入插入模式，打字编辑
  • Esc：退出命令模式
  • :w 保存
  • :q 退出
  • :wq 保持并退出
  • :q! 不保存强制退出
  • /字符串，可以搜索指定字符串（普通模式）
  • :set number ：开启行号显示（命令模式）
  • :行号 ：跳转到指定行号（命令模式）

特殊符号与Shell 进阶

  1. 通配符
  • * ：匹配任意长度的任意字符 ​- ? ：匹配单个任意字符
  •  [] ：匹配括号内的任意单个字符，例如  [a-z]  匹配小写字母。
  1.  重定向
  •  > ：标准输出重定向，覆盖原有文件内容。
  •  » ：标准输出追加，在文件末尾添加内容。
  •  < ：标准输入重定向，从文件读取输入。
  1.  管道符  | 
  • 将前一个命令的输出作为后一个命令的输入，例如  ls | grep “txt”  列出当前目录下的  .txt  文件。
  1.  变量
  • 定义变量： 变量名=值 （等号两侧不能有空格）。
  • 引用变量： $变量名  或  ${变量名} 。
  • 环境变量：系统全局变量，例如  PATH  定义命令搜索路径， HOME  指向用户家目录。
  1.  引号
  • 单引号  ’’ ：原样输出内容，不解析变量。
  • 双引号  "" ：解析其中的变量。
  • 反引号   ：执行命令并返回结果，例如  echo  date 输出当前时间。

用户与权限

  1.  用户与用户组
  •  whoami ：查看当前用户名。
  •  id ：查看用户的 UID、GID 及所属用户组。
  •  useradd ：创建用户， userdel ：删除用户。
  •  groupadd ：创建用户组， groupdel ：删除用户组。
  1.  权限管理
  • 文件权限表示： r （读，4）、 w （写，2）、 x （执行，1），分为所有者、所属组、其他用户三类。
  •  chmod ：修改文件权限，例如  chmod 755 file （所有者读写执行，组和其他用户读执行）、 chmod u+x file （给所有者添加执行权限）。
  •  chown ：修改文件所有者和所属组，例如  chown user:group file 。
  •  sudo ：以管理员身份执行命令，例如  sudo apt update 。

软件包管理（Ubuntu 为例）

  1. apt 命令
  •  sudo apt update ：更新软件源列表。
  •  sudo apt install 包名 ：安装软件包。
  •  sudo apt remove 包名 ：卸载软件包， –purge  可删除配置文件。
  •  sudo apt upgrade ：升级所有已安装的软件包。
  •  sudo apt search 关键词 ：搜索软件包。

远程操作

  1. SSH 远程连接
  • 命令格式： ssh 用户名@主机地址 ，例如  ssh root@192.168.1.100 。
  • 首次连接会提示确认主机密钥，输入  yes  并回车。
  1.  SCP 文件传输
  • 从本地上传到远程： scp 本地文件路径 用户名@主机地址:远程路径 。
  • 从远程下载到本地： scp 用户名@主机地址:远程文件路径 本地路径 。

系统与磁盘管理

  1. 系统资源查看
  •  top / htop ：实时查看进程、CPU、内存使用情况， q  退出。
  •  ps ：查看进程状态， ps aux  显示所有进程详细信息。
  •  kill ：终止进程， kill 进程ID ， kill -9 进程ID  强制终止。
  •  df ：查看磁盘分区使用情况， df -h  人性化显示大小。
  •  du ：查看目录/文件占用磁盘空间大小， du -sh 目录名 。
  1. 磁盘挂载
  •  mount ：挂载磁盘分区，例如  mount /dev/sdb1 /mnt 。
  •  umount ：卸载磁盘分区，例如  umount /mnt 。

环境变量与配置文件

  1. 环境变量配置
  • 临时设置： export 变量名=值 ，仅当前 Shell 有效。
  • 永久设置：修改  ~/.bashrc （当前用户生效）或  /etc/profile （所有用户生效），修改后执行  source 配置文件  生效。
  1. Bash 配置文件
  •  ~/.bashrc ：用户级 Shell 配置文件，可设置别名、环境变量、自定义函数。
  • 常用配置示例： alias ll=‘ls -l’ （给  ls -l  起别名  ll ）。

其他实用命令

  1. date ：查看当前系统时间。
  2. watch ：周期性执行命令，例如  watch -n 2 date  每 2 秒执行一次  date 。
  3. diff ：比较两个文件的差异。
  4. uname ：查看系统信息， uname -a  显示内核版本、系统架构等
